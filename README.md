# Solenne Vey — demo gallery site

A static artist-site demo for a **fictional** painter, Solenne Vey. It is meant to show galleries and artists how a viewing page can work: a hang of works, filters, a keyboard lightbox, and WhatsApp inquiries. Nothing is for sale here. There is no cart and no checkout.

Intended live page: https://mohammedbagowabair.github.io/Solenne-Vey-Art-Gallery-Website/

The site files are on `main` at the repository root. GitHub Pages is not on yet: the token available to this project cannot change Pages settings (`403 Resource not accessible by integration`). Turn it on once in the repository:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Branch **main**, folder **/ (root)**, then save.

GitHub will publish the URL above. No build step is required.

## Stack

Plain HTML, CSS, and JavaScript at the repository root. GitHub Pages serves the `main` branch from `/`. No build step.
